# Sprite Animation Skill

## Overview
This skill guides the AI in handling frame-based sprite animations within Phaser 2D games. It is specifically designed to work with spritesheets generated by the `generate_spritesheet` tool.

## 0. Generating Spritesheets
Use the `generate_spritesheet` tool to create new animations.

### Best Practices for Generation:
1. **Consistency**: Always use the `referenceSpritesheet` parameter if you are creating a new animation for an existing character. This ensures the character's height, scale, and style remain identical between sheets.
2. **Character Design**: If a static character design image exists, provide it via the `characterDesign` parameter. This helps the model maintain accurate colors and features.
3. **Filenames**: Use descriptive filenames that reflect the action (e.g., `warrior_idle`, `warrior_strike`). files are saved in `assets/generated/`.
4. **Grids**: Standardize on a grid like "4x4" (16 frames) for smooth animations or "2x2" for simpler effects.
5. **Tool Call Example**:
```json
{
  "filename": "slime_jump",
  "prompt": "a cute blue slime creature jumping up and down",
  "grid": "4x4",
  "characterDesign": "assets/slime_design.png",
  "referenceSpritesheet": "assets/generated/slime_idle.png"
}
```

## 1. Loading Spritesheets
In the `preload()` method of your Scene, load the spritesheet. You must specify the correct `frameWidth` and `frameHeight` based on the grid layout used during generation.

```typescript
// Example: If a 1024x1024 sheet was generated with a "4x4" grid
this.load.spritesheet('character_walk', 'assets/generated/character_walk.png', {
    frameWidth: 256, // 1024 / 4
    frameHeight: 256  // 1024 / 4
});
```

## 2. Defining Animations
In the `create()` method, or a dedicated animation manager, define the animation sequences.

```typescript
this.anims.create({
    key: 'walk',
    frames: this.anims.generateFrameNumbers('character_walk', { 
        start: 0, 
        end: 15 // For a 4x4 grid (0-15)
    }),
    frameRate: 12,
    repeat: -1 // Loop indefinitely
});
```

## 3. Playing Animations
Create a sprite and play the animation.

```typescript
const player = this.add.sprite(x, y, 'character_walk');
player.setScale(0.5); // the animation size may need scaling to match the player size
player.play('walk');
```

## 4. Best Practices for Combat Effects
When using animations for one-off effects (explosions, magic hits):
1. Create the sprite at the target's position.
2. Play the animation once.
3. Automatically destroy the sprite when the animation finishes.

```typescript
function playEffect(scene, x, y, effectKey) {
    const effect = scene.add.sprite(x, y, effectKey);
    effect.play(effectKey);
    effect.on('animationcomplete', () => {
        effect.destroy();
    });
}
```

## 5. Integrating with Generated Assets
When the `generate_spritesheet` tool provides an output path, use that path in your loading logic. Always check the `grid` parameter of the tool output to calculate the correct frame dimensions.
